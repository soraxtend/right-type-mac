# RightType for macOS

พอร์ต [RightType](https://github.com/k-affan-th/RightType) (ของ Windows) มาใช้บน Mac
แก้ข้อความที่พิมพ์ผิดแป้น ไทย ↔ อังกฤษ โดยไม่ต้องลบแล้วพิมพ์ใหม่ เช่น `l;ylfu` → `สวัสดี`, `แนพพำแะ` → `correct`

ส่วนที่ตัดสินว่าคำไหนพิมพ์ผิดภาษาคือแกน Rust ของ RightType ตัวจริง (ดิกชันนารีและกฎเดียวกัน)
ดึงมาจาก GitHub แบบ pin commit ไว้ ส่วนที่เขียนใหม่สำหรับ Mac มีแค่ตัวดักคีย์ การพิมพ์แทน การสลับคีย์บอร์ด และเมนูบาร์

## ใช้งาน

| ปุ่ม | ทำอะไร |
| --- | --- |
| `⇧⌫` (Shift+Delete) | แก้คำล่าสุด กดซ้ำเพื่อแก้คำก่อนหน้าเพิ่ม (สูงสุด 8 คำ) กดอีกทีหลังแก้ครบแล้วจะย้อนกลับทั้งหมด |
| `⌃⇧⌫` | แก้ข้อความที่เลือกไว้ทั้งก้อน (ใช้คลิปบอร์ดชั่วคราว แล้วคืนของเดิมให้) |
| `Tab` | ใช้คำแนะนำของโหมดแนะนำ (ภายใน 4 วินาที) |
| `⌃⌥Space` | Command palette: แก้/เปลี่ยนข้อความที่เลือก, โหมด, หยุดชั่วคราว, ปิดในแอปนี้, ตัวเลือก |

โหมดเลือกได้จากไอคอน **Aก** บนเมนูบาร์ หน้าตั้งค่า หรือ palette

- **อัตโนมัติ** (ค่าเริ่มต้น): แก้ตั้งแต่ระหว่างพิมพ์เหมือนตัว Windows ไม่ต้องรอวรรค ภาษาไทยที่พิมพ์ติดกันยาวๆ ก็แก้ได้ (ฝั่งอังกฤษที่พิมพ์ตอนแป้นเป็นไทยยังแก้ตอนจบคำ) ถ้าแก้ผิด กด `⇧⌫` เพื่อย้อน
- **แนะนำ** (Suggest): ไม่แตะข้อความเอง แสดงคำที่แก้แล้วข้างเคอร์เซอร์ กด `Tab` เพื่อใช้ (ระหว่างพิมพ์คำไทยก็แสดง)
- **แก้เมื่อจบคำ** (Semi-auto, มีเฉพาะบน Mac): แก้ให้เองเมื่อเคาะวรรคหรือกด Enter แล้วสลับคีย์บอร์ดให้
- **กดแก้เอง** (Manual): แก้เฉพาะตอนกด `⇧⌫`

หน้า **ตั้งค่า…** ทำตามหน้าตั้งค่าของตัว Windows: ทั่วไป, แป้นพิมพ์, เครื่องมือ (หน้าต่างซ่อมข้อความ),
ปุ่มลัด, คำที่จำไว้, คำย่อ, แอปที่ไม่ใช้, ความเป็นส่วนตัว, สนับสนุน

- **คำที่จำไว้**: กด `⇧⌫` ย้อนคำที่ RightType แก้ให้ คำเดิมจะถูกจำไว้และไม่ถูกแก้อีก
  เปิด "เรียนรู้คำใหม่" เพื่อให้จำคำอังกฤษที่พิมพ์ซ้ำ 3 ครั้งด้วย (ปิดไว้ก่อน) เพิ่ม ลบ นำเข้า ส่งออกได้
  เก็บที่ `~/Library/Application Support/RightType/learned.txt`
- **คำย่อ** (snippets): `;addr` + วรรค → ข้อความเต็ม ใช้ได้บนแป้นไทย แป้นอังกฤษ หรือทั้งสอง
  มีช่องวันที่/เวลา (`{วันที่}`, `{iso}` ฯลฯ) และ macro (`{กด Cmd+B}`, `{รอ 300}`, `{คลิปบอร์ด}`)
  และ "คำผิดของฉัน" ที่แก้คำที่พิมพ์ผิดประจำให้เมื่อจบคำ
- **โหมดแต่ละแอป** (เมนู Aก → ในแอปนี้ หรือ ตั้งค่า → แอปที่ไม่ใช้): ตั้งโหมดเฉพาะแอปได้ หรือปิดในแอปนั้น
  โปรแกรมเขียนโค้ด (VS Code, Cursor, Xcode, JetBrains, Zed, Sublime ฯลฯ) เริ่มที่ **โหมดกดแก้เอง**
  ชื่อตัวแปรและคำสงวนจึงไม่ถูกแก้ระหว่างพิมพ์ กด `⇧⌫` เมื่ออยากแก้คำที่พิมพ์ผิดภาษา
- ตัวเลือกจากตัว Windows: แก้คำไทยที่สะกดผิดบ่อย, แก้เว็บ อีเมล ตัวเลขที่พิมพ์บนแป้นไทย, หยุดชั่วคราว

## ติดตั้ง

คู่มือติดตั้งทีละขั้นสำหรับคนทั่วไป (รวมวิธีแก้ปัญหาและถอนการติดตั้ง) อยู่ที่ [INSTALL.md](INSTALL.md)
ส่วนนี้สำหรับคนที่ build เอง

ต้องมี Xcode Command Line Tools กับ rustup (`brew install rustup` แล้ว `$(brew --prefix rustup)/bin/rustup default stable`)
ใช้ rustup ไม่ใช้ `brew install rust` เพราะไลบรารีของ Rust จาก Homebrew build มาสำหรับ macOS รุ่นล่าสุด แอปจะเปิดบน macOS รุ่นเก่าไม่ได้ (`build.sh` จะไม่ยอม build ให้)

```bash
./build.sh install
```

แล้วเปิด `/Applications/RightType.app` และให้สิทธิ์ที่
System Settings → Privacy & Security → **Accessibility**

> แอปเซ็นแบบ ad-hoc macOS ผูกสิทธิ์ Accessibility ไว้กับลายเซ็นของแต่ละ build
> ทุกครั้งที่ build ใหม่ต้องลบ RightType ออกจากรายการ (−) แล้วเพิ่มกลับ (+)

ทดสอบอัตโนมัติ (พิมพ์จำลองผ่านตัวดักคีย์จริงในหน้าต่างทดสอบของแอปเอง):

```bash
open -W --stdout /dev/stdout -a /Applications/RightType.app --args --selftest
```

ทดสอบโหมดแต่ละแอปใน VS Code จริง (เปิด VS Code อีกตัวด้วย profile ชั่วคราว ไม่แตะของเดิม แล้วปิดเอง):

```bash
open -W --stdout /dev/stdout -a /Applications/RightType.app --args --selftest-editors
```

เทสต์ของแกน: `./build.sh test`

## คีย์บอร์ดที่รองรับ

แอปดูว่าคีย์บอร์ดเป็นไทยหรืออังกฤษจากตัวอักษรที่แต่ละปุ่มพิมพ์ออกมา ไม่ได้ดูจากชื่อ
คีย์บอร์ดที่ทำเองด้วย Ukelele จึงใช้ได้ถ้าวางปุ่มแบบเกษมณีหรือ US

- ไทย: Thai (เกษมณี) ของ Apple หรือ layout อื่นที่วางแบบเกษมณี
- อังกฤษ: ABC, U.S.
- อื่นๆ (ปัตตะโชติ, Dvorak, IME ภาษาอื่น): แอปจะไม่ยุ่ง

## ความเป็นส่วนตัว

- ไม่มีโค้ดเครือข่าย ไม่บันทึกสิ่งที่พิมพ์ลงดิสก์ เก็บแค่คำที่กำลังพิมพ์ในหน่วยความจำ แล้วล้างทิ้ง (zeroize)
- สิ่งเดียวที่เขียนลงดิสก์คือคำที่จำไว้ (คำที่คุณย้อนกลับเอง หรือเพิ่มเอง หรือคำอังกฤษที่พิมพ์ซ้ำเมื่อเปิดการเรียนรู้) และคำย่อที่ตั้งเอง ดูและลบได้ในหน้าตั้งค่า
- ช่องรหัสผ่าน: macOS เปิด Secure Input ซึ่งไม่ส่งปุ่มให้แอปไหนดักได้อยู่แล้ว
- ปิดใน Terminal, iTerm, Ghostty, 1Password, Bitwarden, Keychain, Remote Desktop ฯลฯ ตั้งแต่แรก

## ยังไม่ได้พอร์ต

ตัว Windows ยังมีเครื่องมืออีกหลายอย่างที่ผูกกับ Windows หรือยังไม่มีที่นี่ เช่น
รายการอักขระพิเศษที่เคอร์เซอร์ (Shift สองครั้ง), แผนผังคีย์บอร์ด, ฝึกพิมพ์, ปุ่มลัดที่ตั้งใหม่ได้,
โฟลเดอร์ซิงก์คำที่จำไว้ และหน้าภาษาอังกฤษของ UI

## โครงสร้าง

```
core/      Rust: เรียก righttype (แกนของตัว Windows) แล้วเปิดเป็น C API (core/include/righttype.h)
           รวมคำที่จำไว้ (core/src/learn.rs) คำย่อ/macro และการเปลี่ยนข้อความของ palette
app/       Swift: event tap, พิมพ์แทน, สลับ input source, เมนูบาร์, ป้ายคำแนะนำ, palette, หน้าตั้งค่า, self-test
tools/     make_icon.swift วาดไอคอนแอป (app/AppIcon.icns)
           (ดูหน้าตั้งค่าโดยไม่ต้องให้สิทธิ์: RightType --render-settings <โฟลเดอร์> วาดทุกหน้าเป็น PNG)
build.sh   build ทั้งสองส่วนเป็น build/RightType.app
```
